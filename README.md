# Overview

Module `go.bytecodealliance.org/pkg` contains packages required for building components with [componentize-go](https://github.com/bytecodealliance/componentize-go).

## Packages

| Package | Description |
| --- | --- |
| `wit/types`, `wit/runtime`, `wit/async` | Core WIT value types (option, result, tuple, stream, future) and the canonical-ABI runtime support used by generated bindings. |
